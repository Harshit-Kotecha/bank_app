# Bank App UI - Flutter Project

## Overview

This project is a Flutter-based UI for a bank app. It was built to explore and implement modern practices in mobile app development, focusing on clean and modular code. The app includes features like a user dashboard, financial visualizations, and secure authentication.

## Features

- **Dio**: Used for handling API requests efficiently.
- **GetX**: For state management, providing a reactive and easy-to-use approach.
- **MVC Architecture**: Organized the app following the Model-View-Controller pattern to separate concerns and improve maintainability.
- **Custom Graphs and Pie Charts**: Visualize finances with customizable graphs and pie charts, including filters for detailed insights.
- **User Dashboard**: A comprehensive dashboard displaying all relevant financial information in one place.
- **Firebase Integration**: For backend services like authentication, analytics, and more.
- **Google Sign-In**: Allows users to sign in securely using their Google account.

## Getting Started

To run this project on your local machine:

1. Clone the repository.
2. Open the project in your preferred IDE (e.g., Android Studio or VS Code).
3. Run `flutter clean` and then `flutter pub get` to install dependencies.
4. Configure Firebase in your project by adding your `google-services.json` file.
5. Run the app on an emulator or physical device.
